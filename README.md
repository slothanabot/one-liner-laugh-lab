A make.fun entry for the "One-Liner Laugh Lab" bounty: a tiny deterministic program that writes one short funny line — the excuse a robot vacuum gives after eating a sock — to `entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
